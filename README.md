# VOLTWAY — Electric Vehicle Dealership Website

Short page names:
- index.html — Home
- home2.html — Home 2
- about.html — About
- models.html — EV Models
- charge.html — Charging & Range
- savings.html — Savings Calculator
- locations.html — Dealership Locations + Test Drive
- contact.html — Contact alias
- dashboard.html — Customer Dashboard
- login.html / signup.html — Authentication screens

Run: Extract the ZIP and open index.html. Internet access is needed for Google Fonts, remote photos and OpenStreetMap.

Features: responsive layout, persistent Light/Dark mode, whole-page LTR/RTL direction toggle, mobile navigation, interactive savings estimate, validated demo enquiry/newsletter/auth forms, dashboard mock-up and map preview.

Production requirements: demo forms do not send data; login/signup require secure authentication; dashboard data, test-drive booking, vehicle inventory and telemetry need backend integrations. Replace placeholder dealership address/map with verified details. Verify all prices, ranges, warranties, charging times, subsidy claims and specifications before publishing. Do not use sample figures from the source blueprint as real claims.
